## 🚀 Featured Projects

### 📡 NetPulse — Network Monitoring

[![NetPulse](https://img.shields.io/badge/VIEW_PROJECT-181717?style=for-the-badge&logo=github)](https://github.com/JoseVitor-net/NetPulse)

Ferramenta desktop de monitoramento de rede com análise de conectividade e visualização em tempo real.

- Monitoramento simultâneo de múltiplos hosts.
- Diagnóstico de conectividade ICMP.
- Análise de falhas e correlação entre rotas.
- Dashboard de monitoramento.
- Histórico e reprodução de sessões.
- Armazenamento local com SQLite.

**Technologies:** Python · PyQt6 · PyQtGraph · SQLite
